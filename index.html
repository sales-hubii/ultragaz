Piloto Digital P13 via Marketplaces

✓ Fase 1 (Piloto): Integração com iFood, 99Food, Magalu e Aiqfome no mercado GSP (Grande São Paulo). Foco inicial: produtos select de gás em cilindro + acessórios.

✓ Fase 2: Expansão para outros segmentos de produto (equipamentos de climatização, peças de reposição).

✓ Fase 3 (Futuro): Integração com plataformas de B2B (compras.com.br, agro-traders).

Modelo anterior descontinuado: WhatsApp + equipe manual foi interrompido. Pivô: automatizar via APIs de marketplaces.

🚀 Oportunidades Identificadas
Automação de Fulfillment
Integração com sistema de warehouse para picking/packing automático de pedidos marketplace.
White Label em Terceiros
Monetizar marketplace de gás para distribuidoras regionais como B2B2C (modelo SaaS).
Cross-selling com Acessórios
Ofertas inteligentes de componentes, cilindros e peças durante compra de gás.
⚠️ Desafio: Custo de Delivery
Gás em cilindro é pesado — frete onerado em marketplaces. Precisa estratégia de absorção de custo ou modelo de recarga.
⚠️ Desafio: Regulação de Transporte
Cilindros de gás têm restrições de transporte (classificação de periculosidade). Validar compliance com plataformas.
